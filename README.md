## Job portal

A web-based job portal developed using ASP.NET MVC where companies can register, post jobs, and users can search and apply for jobs.

## Technologies Used

- Asp.net MVC
- C#
- Entity Framework
- SQL Server
- HTML5
- CSS3
- Bootstrap
- JavaScript
- jQuery
- Visual Studio
- Git & GitHub

## Features

- User Registration and Login
- Company Registration and Login
- Job Posting
- Job Search
- Job Application
- Application Status
- Database Management

## Database
- Microsoft SQL Server
- Entity Framework / EDMX
- Stored Procedures
